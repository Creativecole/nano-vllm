# Qwen3.5 Hybrid Correctness

This file is generated by a real-checkpoint RTX 5090 run. No numerical result is
recorded before the run completes.

```bash
python benchmarks/qwen35_hybrid/validate_checkpoint.py \
  --model ../models/Qwen3.5-9B

python benchmarks/qwen35_hybrid/validate_correctness.py \
  --model ../models/Qwen3.5-9B \
  --prompt-lens 1,16,128,512 \
  --batch-sizes 1,2,4 \
  --decode-steps 1,8,32
```

The generated report includes final-logit error, selected decode-logit error,
greedy-token agreement, and the first decoder layer outside the configured
`atol`/`rtol` threshold.
